# Ab3lo Portfolio

My personal portfolio site built in NUXT

## About

This site was **agentically created and developed using AI assistants**. It is built on top of **Hugo Richard's [Nuxt Canvas](https://canvas.hrcd.fr/) theme**, a clean, minimalist portfolio template for designers and developers built with Nuxt and Tailwind CSS, then customized with AI assistance into a full personal portfolio.

## Tech Stack

- **[Nuxt 4](https://nuxt.com)** — Vue 3 meta-framework (static prerender)
- **[Nuxt UI](https://ui.nuxt.com)** — Tailwind-based UI components
- **[Nuxt Image](https://image.nuxt.com)** — optimized/responsive images
- **Vue Sonner** — toast notifications
- **[Iconify](https://iconify.design)** — icons (custom + simple-icons sets)
- **Tailwind CSS** — styling

## Features

- Home, About, Projects, Contact pages
- Project showcase with an e-commerce / full-stack focus
- Dark mode by default
- Fully static, prerendered output — deployable to any static host

## Development & Deploy

- `npm install` — install dependencies
- `npm run dev` — local dev server
- `npm run generate` — prerender static site (35 routes) to `.output/public`
- `npm run deploy` — deploy via the GitHub Actions workflow to GitHub Pages

Deployed via GitHub Actions to https://ab3lo.github.io/portfolio/ (base path `/portfolio/`).
